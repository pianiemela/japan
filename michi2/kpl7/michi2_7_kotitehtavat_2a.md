1 むらさきいろのわんぴいすおきていろおんあのひとはりいささんです

With kanji where natural, I would write it as:

**紫色のワンピースを着ている女の人はリーサさんです。**



Breakdown:

* むらさきいろ → **紫色**（むらさきいろ） = purple
* わんぴいす → **ワンピース** = one-piece dress
* きている → **着ている** = wearing
* おんなのひと → **女の人**（おんなのひと） = woman
* りいさ → **リーサ** = Riisa/Liisa
* さん → **さん**

So the sentence means:
  

> **The woman wearing a purple dress is Liisa.**



2 
The natural kanji version is:

**白いTシャツを着ている男の人はペッカさんです。**

Breakdown:

* しろい → **白い**（しろい） = white
* Tーしぇす → **Tシャツ** = T-shirt
* きている → **着ている**（きている） = wearing
* おとこのひと → **男の人**（おとこのひと） = man
* ぺっか → **ペッカ** = Pekka
* さん → **さん**

**Meaning:**

> The man wearing a white T-shirt is Pekka.

3 くろずぼんをきているだんせいはさろねんさんです

The natural kanji version is:

**黒いズボンを着ている男性はサロネンさんです。**

Kuroi zubon o kite iru dansei wa saronen-sandesu.

Breakdown:

* くろい → **黒い**（くろい） = black
* ずぼん → **ズボン** = trousers/pants
* きている → **着ている**（きている） = wearing
* だんせい → **男性**（だんせい） = man/male
* さろねん → **サロネン** = Salonen
* さん → **さん**

**Meaning:**

> The man wearing black trousers is Mr. Salonen.
