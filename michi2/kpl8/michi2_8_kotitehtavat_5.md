Tässä on täydennetyt lauseet sekä korjaukset tekstissä olleisiin kirjoitusvirheisiin:

あそこ**に** とてもきれいな おんなのひと**が** います。

たかそうな くるまの なか**で** ざっしを よんでいます。

だれでしょうか。

ああ、わかりました。

たいへん ゆうめいな じょゆう**の** きむら えみこさんです。

---

### Partikkelien selitykset

* **あそこに (asoko ni):** Paikkapartikkeli **に (*ni*)**, koska lauseessa ilmaistaan jonkin/jonkun olemassaoloa verbillä *imasu*.
* **おんなのひとが (onna no hito ga):** Subjektipartikkeli **が (*ga*)**, joka ilmaisee olemassaololauseen tekijän (*imasu*-verbin yhteydessä).
* **なかで (naka de):** Paikkapartikkeli **で (*de*)**, koska autossa *tehdään jotain* (luetaan lehteä / *yonde imasu*).
* **じょゆうの (joyū no):** Omistus-/määritepartikkeli **の (*no*)**, joka yhdistää kaksi substantiivia: "kuuluisa näyttelijä **Emiko Kimura**" (*joyū no Kimura Emiko-san*).


Tässä on koko vuoropuhelu ja tarina kanjeilla (ja kanji-hiragana -segmenteillä) kirjoitettuna. Furiganat (lukuasut) on merkitty sulkuihin kanjien jälkeen lukemisen helpottamiseksi:

### Keskeiset kanjit ja niiden merkitysekset:

* **女の人** (*onna no hito*) = nainen (**女** = nainen, **人** = ihminen)
* **車** (*kuruma*) = auto
* **中** (*naka*) = sisällä / keskellä
* **雑誌** (*zasshi*) = aikakauslehti
* **読** (*yo-mu*) = lukea (**読んでいます** = on lukemassa)
* **誰** (*dare*) = kuka
* **分** (*wa-karu*) = ymmärtää / tietää (**分かった** = ymmärsin)
* **有名** (*yūmei*) = kuuluisa (**有** = olla/omistaa, **名** = nimi)
* **女優** (*joyū*) = näyttelijätär (**女** = nainen, **優** = näyttelijä/ystävällinen)
* **母** (*haha*) = äiti (oma)
* **一番** (*ichiban*) = paras / ensimmäinen / eniten
* **好** (*suki*) = pitää jstk / mieluisa
* **髪** (*kami*) = hiukset
* **短** (*miji-kai*) = lyhyt
* **目** (*me*) = silmä
* **大** (*ō-kii*) = suuri

### Mielenkiintoiset rakennetärpit lauseessasi:

1. **『ラブ・ストーリー』んです (*nan desu*):**
* Lopussa oleva **んです (*n desu*)** tuo lauseeseen selittävän tai taustoittavan sävyn ("kyse on siis tästä elokuvasta"). Se sitoo vastauksen hienosti edelliseen keskusteluun.


2. **好きじゃない deskö $\rightarrow$ 好きじゃないんですけどね (*suki ja nai n desu kedo ne*):**
* **～ provides/kedo:** "vaikka / mutta". Pehmentää ilmaisua, ettei se kuulosta liian jyrkältä.
* **ね (*ne*):** Hakemaan yhteymmärrystä tai pehmentämään lopetusta ("nähdäkseni / natsaako").


3. **Lainausmerkit 『 』:**
* Japanissa kirjojen, elokuvien ja teosten nimet kirjoitetaan kulmakonserttimaisilla lainausmerkeillä 『 』 tavallisten 「 」 sijaan.
